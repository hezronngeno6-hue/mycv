# Hezron Kipkorir — Personal CV Website

A simple static personal website (plain HTML/CSS, no build step) hosted on Vercel.

## Pages

| Page | File |
| --- | --- |
| Home | `index.html` |
| Education | `education.html` |
| Experience | `experience.html` |
| Hobbies | `hobbies.html` |
| Contacts | `contacts.html` |

## Local preview

Open `index.html` in any browser, or run:

```powershell
npx serve .
```

## Deployment

Deployed with Vercel as a static site — every push to `main` triggers a new production deploy.
